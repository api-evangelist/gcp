Google Cloud announced the preview of native graph algorithms within Spanner Graph, bringing Google Research's graph mining capabilities directly to the database for fraud detection, entity resolution, and network analysis at scale. The algorithms integrate with ISO Graph Query Language (GQL) and use dedicated compute resources via Data Boost to analyze billions-edge graphs without impacting operational database performance. Enterprises can now derive graph-based intelligence from their operational data without extracting it to a separate analytics system.
