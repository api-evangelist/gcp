Google Cloud announced major enhancements to Managed Service for Apache Spark clusters focused on three pillars: faster performance through the new Lightning Engine delivering up to 4.9x speed improvements, easier operations via Flexible VMs and zero-scale clusters, and smarter capabilities through Gemini-powered extensions and a Model Context Protocol server. The update includes support for Spark 4.1 with real-time streaming capabilities and integration with the new Lakehouse platform for unified metadata management across engines. These improvements target data engineering teams running large-scale batch and streaming workloads on Google Cloud.
